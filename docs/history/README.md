- [Progress through October 19, 2026](progress-through-2026-10-19.md): the prior tracker, including dated verification, development decisions, and delivery records. Its relative links retain their original context under `context/`; they are not current navigation links.

Current requirements live in [project requirements](../../context/project-requirements.md), with current status in the [progress tracker](../../context/progress-tracker.md).
